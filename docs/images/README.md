# 截图拍摄清单

README 里已经写好了占位注释，图片放进这个目录、按下面的文件名保存，
然后把对应注释块删掉、保留里面那行 `![]()` 就行。

拍摄前的通用准备：

- 用一个**干净的 Zotero 开发 profile**，文库里只留下要出镜的那几条文献。
- 窗口宽度调到 1440 左右，别用超宽屏 —— README 里图会被缩到很小。
- 用浅色主题（GitHub 深色模式下浅色截图更清楚，反过来不成立）。
- 挑一篇**可以公开的论文**（开放获取的最好），别让未发表内容或个人信息入镜。
- 设置面板出镜前先把 API Key 清空或改成 `sk-****`。

## 1. `demo-selection.gif` — 首屏演示（最重要）

6~10 秒，展示这个插件最核心的价值：

1. 在 PDF 里划选一个**带术语的句子**（不要选单个词，选句子更能体现"上下文"）
2. 浮层出现，点"翻译"
3. 让它录到本地词典/首屏内容先出现、大模型译文再流式补上的过程
4. 结果稳定后停 1 秒结束

要点：**不要加速**，流式补充的过程本身就是卖点。宽度控制在 900px 以内，
文件大小尽量压到 5MB 以下（GitHub 上超过这个尺寸加载会很慢）。

## 2. `preferences.png` — 设置面板

设置 → Context Translate 的完整面板，能看到 LLM 配置、触发方式、
解析模式、术语表和词典几块。**API Key 记得打码。**

## 3. `popup.png` — 翻译浮窗

翻译一个**段落**，让浮窗同时显示上半区译文和下半区的语境解析
（衔接关系、核心论点），这样最能体现两栏结构。连同周围一点 PDF 正文一起截，
让人看得出它浮在阅读器上。

## 4. `bilingual-html.png` — 双语 HTML

生成好的 HTML 在 Zotero 快照阅读器里打开，切到**双语模式**，
让左侧的语言切换栏和中英对照的正文都在画面里。最好能截到一张图或一个表格，
体现 MinerU 高保真解析的效果。

## 5. `workbench.png` — 工作台

切到"整篇翻译任务"页签，最好有**一个正在跑的任务**（能看到阶段和进度条）
加上一两个已完成的任务。文献标题如果不方便公开可以先改掉。
