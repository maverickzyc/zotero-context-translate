# v0.2.0 — Context Translate 工作台

> 2026-07-25

## 安装

Zotero 9 → Tools → Plugins，将 `zotero-context-translate-0.2.0.xpi`
拖入窗口，或使用 Plugins 窗口中的“Install Plugin From File”。

升级后请完全退出并重新启动 Zotero。

## 新工作台

从“工具 → Context Translate 工作台”打开：

- “查词与翻译历史”：查看词、句子、段落翻译及其上下文，支持搜索、复制、
  定位条目和删除。
- “整篇翻译任务”：查看解析、结构识别、术语、翻译、校验、HTML 渲染和
  Zotero 附件保存的完整阶段。
- 每个任务展示总体进度、内容块进度、Token 用量、更新时间及错误详情。
- 支持暂停、继续、取消、定位原 PDF 和打开已完成的双语 HTML。

## 恢复修复

- 点击“继续”后会立即显示“正在恢复任务”。
- 恢复失败会显示具体错误，不再静默无响应。
- Zotero 重启后保留或推断任务中断前所在阶段。
- 面板打开期间任务进度实时刷新。

## 兼容性

- 主测试版本：Zotero 9.0.6。
- 声明兼容范围：Zotero 8.0–9.0.x。
- 50 项测试已在真实 Zotero 9.0.6 进程中通过。
